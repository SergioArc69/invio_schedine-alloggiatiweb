# invio_schedine-alloggiatiweb
Invio schedine su [AlloggiatiWeb*](https://alloggiatiweb.poliziadistato.it/PortaleAlloggiati/) tramite Username/Password e **WebServiceKey**.

L'applicazione **InvioSchedineAlloggiatiWeb** prevede l'invio delle schedine tramite il caricamento di un file .txt prodotto da strumenti esterni e contenente i record, ovvero tramite editing diretto delle singole schedine, secondo le [specifiche](https://alloggiatiweb.poliziadistato.it/PortaleAlloggiati/Download/Manuali/MANUALEWS.pdf) del Portale Alloggiati della Polizia di Stato.

L'applicazione consente anche il download della ricevuta in formato pdf, prodotta dal Portale Alloggiati, degli invii effettuati.
